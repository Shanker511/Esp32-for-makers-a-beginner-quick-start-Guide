# Parts List

Suggested starter parts for **ESP32 for Makers**.

## Core

- ESP32 development board
- USB data cable
- Breadboard
- Male-to-male jumper wires

## Basic output

- LEDs
- 220 ohm or 330 ohm resistors
- Piezo buzzer

## Basic input

- Push buttons
- PIR motion sensor
- Light sensor module
- DHT11 temperature and humidity sensor

## Display

- I2C OLED display
- Common wiring:
  - VCC
  - GND
  - SDA
  - SCL

## Notes

Check voltage before wiring. Many ESP32 GPIO pins are **not 5V tolerant**.
